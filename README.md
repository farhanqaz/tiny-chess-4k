A chess engine in under 4 KB of Python: precomputed ray, knight and pawn tables,
pseudo-legal move generation with legality checked after the move, an incremental
material-plus-piece-square evaluation, and alpha-beta search with quiescence,
killers, MVV-LVA ordering and a transposition table. It plays the make.fun
gauntlet through the trial environment over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
